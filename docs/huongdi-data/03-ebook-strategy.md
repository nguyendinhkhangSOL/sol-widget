**Status:** Plan only — chưa triển khai ngay. Ưu tiên sau khi: pillar pages có 1000+ pageview/tháng + Newsletter list có 200+ subs.

## I. Vì sao cần Ebook?

### Pain point hiện tại
- Pillar page hay → user đọc 5-10 phút → đóng tab → KHÔNG có cách re-engage
- Không có email list → mỗi visit là "tép" mới, không compound
- P3 result đẹp nhưng user rời huongdi → mất luôn lead

### Ebook giải quyết
1. **Email collection** — Mỗi ebook download = 1 email mới
2. **Re-engagement** — Newsletter weekly nurturing → bán coaching/cohort
3. **Brand trust** — PDF 30-50 trang chất lượng → user thấy Sol "serious"
4. **SEO long-tail** — Ebook landing page tự rank cho keyword cụ thể

TRANG 39-44: Phần 5 — FAQ (15-20 câu)

  - Contract template

  - Lời cảm ơn

## IV. Production workflow — Tận dụng content có sẵn

### Phase 1: Convert Pillar Page → Ebook draft (4-6h/ebook)

```
Pillar page (4000 từ trên sol.vn)
    ↓
+ Lời mở đầu cá nhân hoá (600 từ mới)
+ Self-assessment 10 câu
+ Case study expand từ pillar (3-5 anh em)
+ Toolkit + Templates (collect từ kinh nghiệm Khang)
+ FAQ 15-20 câu (từ comment FB Group + email)
    ↓
Ebook draft (~12,000-15,000 từ)
```

### Phase 2: Design layout (4-6h/ebook)

| Tool | Mục đích | Giá |
|---|---|---|
| **Canva Pro** | Layout dễ, có template ebook | 230k/tháng |
| **Affinity Publisher** | One-time license, layout chuyên nghiệp | 1.5tr one-time |
| **Adobe InDesign** | Pro tool nhưng overkill | 800k/tháng |
| **Microsoft Word** | Quick & dirty, export PDF | Free |

→ Recommend **Canva Pro** cho 7 ebook đầu tiên (đơn giản + nhanh).

### Phase 3: Production checklist

- [ ] Cover design (1200×1500 px cho landing + thumbnail)
- [ ] Layout consistent (font, color theo brand Sol)
- [ ] Page numbers + TOC clickable
- [ ] Watermark Sol logo (footer mỗi trang)
- [ ] Hyperlinks tới sol.vn + FB Group hoạt động trong PDF
- [ ] Export quality: PDF/A standard, dưới 5MB
- [ ] Filename: `[number]-[slug]-ebook-sol-v1.pdf`

## V. Hosting + Distribution

### Option A: Self-host trên VPS (recommend)

```
URL: https://sol.vn/ebooks/freelancer-chuyen-mon-tuoi-45.pdf
HOẶC
URL: https://sol.vn/wp-content/uploads/ebooks/[slug].pdf
```

**Pros:**
- Full control, không phụ thuộc dịch vụ ngoài
- Tracking download bằng Nginx log + GA4
- SEO benefit (file URL trên domain Sol)

**Cons:**
- Phải tự setup gate (form → email → unlock URL)

### Option B: ConvertKit / MailerLite (email service tích hợp gate)

| Service | Free tier | Paid |
|---|---|---|
| **MailerLite** | 1000 subs free | 290k/tháng (10k subs) |
| **ConvertKit** | 1000 subs free | 700k/tháng (10k subs) |
| **Beehiiv** | 2500 subs free | 1tr/tháng (10k subs) |

→ Recommend **MailerLite** vì rẻ + có Việt hoá.

### Option C: Gumroad / Lemon Squeezy (paid ebook)

Nếu tương lai muốn bán ebook (49k-149k VND/quyển):
- Gumroad: 10% transaction fee
- Lemon Squeezy: tự xử lý VAT EU + 5% fee

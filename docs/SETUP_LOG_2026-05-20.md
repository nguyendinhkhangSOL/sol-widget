## 11. Troubleshooting — lỗi thường gặp

### Lỗi SSH "Permission denied"

**Triệu chứng**: `Permission denied, please try again` khi SSH.

**Nguyên nhân**:
1. Root login bị disable (PermitRootLogin no) — phải dùng `solop` user
2. SSH key chưa setup đúng
3. fail2ban đã ban IP (sau nhiều lần thử sai)

**Fix**:
```powershell
# Verify cặp key local đúng:
ssh-keygen -y -f $env:USERPROFILE\.ssh\sol_vps

# So fingerprint trên VPS:
ssh sol-vps "ssh-keygen -lf /home/solop/.ssh/authorized_keys"
# Hai fingerprint phải KHỚP

# Debug verbose:
ssh -i $env:USERPROFILE\.ssh\sol_vps -v -o IdentitiesOnly=yes solop@103.72.57.11 hostname
```

### Lỗi sudo cần TTY

**Triệu chứng**: `sudo: a terminal is required to read the password`

**Fix**: Thêm flag `-t` vào ssh:
```powershell
ssh -t sol-vps "sudo <command>"
```

Hoặc tốt hơn: bật NOPASSWD sudo cho solop (xem Section 4).

### Lỗi 502 Bad Gateway

**Triệu chứng**: `curl https://bothuocla.sol.vn` trả 502.

**Nguyên nhân**: Nginx reverse proxy đến `127.0.0.1:3000` (Node app) nhưng app chưa chạy.

**Fix tạm**: Serve static landing page (đã làm).
**Fix dài hạn**: Deploy Sol Widget Node app (Phase tiếp).

### Lỗi Certbot fail "challenge failed"

**Triệu chứng**: Let's Encrypt verify thất bại khi chạy Certbot.

**Nguyên nhân**: Cloudflare đang Proxied (đám mây cam) → Let's Encrypt không reach origin.

**Fix**: Chuyển DNS sang DNS only (đám mây xám) trước, sau khi xong bật lại Proxied.

### Lỗi robots.txt có Cloudflare Managed Content

**Triệu chứng**: `curl https://sol.vn/robots.txt` trả về phần `# BEGIN Cloudflare Managed content` cấm AI bots.

**Fix**: Tắt **Managed robots.txt** toggle trong:
```
Cloudflare → sol.vn → AI Crawl Control → Directives
```

### Lỗi PowerShell paste password vào prompt

**Triệu chứng**: Paste password vào SSH prompt không work, gõ tay thì OK.

**Nguyên nhân**: Bracketed paste mode của terminal.

**Fix**: Dùng SSH key (no password) — vĩnh viễn không cần paste password nữa.

### Lỗi Notepad save SSH config thành `.txt`

**Triệu chứng**: `ssh sol-vps` báo `Could not resolve hostname sol-vps`.

**Fix**:
```powershell
# Rename:
Move-Item $env:USERPROFILE\.ssh\config.txt $env:USERPROFILE\.ssh\config -Force

# Hoặc tạo lại bằng PowerShell (đảm bảo không có .txt):
@"
Host sol-vps
    HostName 103.72.57.11
    User solop
    IdentityFile ~/.ssh/sol_vps
"@ | Out-File $env:USERPROFILE\.ssh\config -Encoding ascii -NoNewline
```

### Lỗi $env:USERPROFILE trong PuTTY

**Triệu chứng**: Lệnh PowerShell `$env:USERPROFILE\...` chạy nhầm trong PuTTY (Linux).

**Fix**: PowerShell lệnh chạy trong PowerShell window, KHÔNG paste vào PuTTY (Linux bash).

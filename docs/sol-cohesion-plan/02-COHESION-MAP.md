## III. The 3 main loops

Hệ thống không phải 1 funnel thẳng — mà là **3 loop tự bồi đắp**:

### Loop 1: SEO Compound Loop
```
Pillar publish → Google index → Search traffic →
   ↓
Newsletter signup + huongdi demo + book preview →
   ↓
Backlinks earn → DA tăng → Pillar rank cao hơn →
   ↓ (loop back to top)
```

→ **Càng nhiều pillar publish, SEO authority compound.**

### Loop 2: Community Trust Loop
```
bothuocla user join → Build trust qua 88-day journey →
   ↓
Recommend Sol books to peers + share huongdi DNA result →
   ↓
New people join bothuocla qua WOM → Repeat →
   ↓ (loop back)
```

→ **Càng nhiều user qua bothuocla, càng nhiều người tin Sol.**

### Loop 3: Customer Lifetime Loop
```
Buy sách V1 → Active 1 năm →
   ↓
Sách V1.5 update FREE for active → Loyalty tăng →
   ↓
Refer friends → Get bonus active extension → Repeat
   ↓
Active renew Year 2 + Cohort upsell → Year 3 advocate
```

→ **CLV = sách 250k → renew 99k/năm × 3 năm + cohort 5tr = ~6tr LTV.**

## V. Cohesion Health Metrics

Đo cohesion 30 ngày sau implement:

| Metric | Target |
|---|---|
| % user từ Pillar đến /sach/ click | 5-8% |
| % user từ huongdi/demo đến /sach/ | 15-20% |
| % user bothuocla day-30 đến /sach/ | 8-12% |
| % user qua >1 domain trong 1 session | 30%+ (sign of trust) |
| Newsletter subs từ Pillar inline form | 3-5% of pillar views |
| FB Group invites từ all sources | 100+/tháng |

→ Nếu các metric trên green → cohesion đang work.

## VI. Anti-pattern — Đừng làm

❌ **Đừng** redirect huongdi.sol.vn về sol.vn (đã fix — landing độc lập)
❌ **Đừng** link huongdi.sol.vn/sach/... (sách ở sol.vn, không phải huongdi)
❌ **Đừng** dùng bothuocla cho marketing aggressive (bothuocla = community first)
❌ **Đừng** tạo thêm subdomain mới (đã có 3, đủ rồi)
❌ **Đừng** tách database user 2 chỗ (1 source of truth tại sol.vn)

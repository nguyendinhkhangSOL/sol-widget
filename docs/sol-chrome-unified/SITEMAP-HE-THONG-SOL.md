## D. QUY TẮC CHỐNG LỘN XỘN

1. **Chỉ sửa menu ở `sol-nav.json`** → mu-plugin (sol.vn) + `sol-chrome.js` (app) tự đọc → 2 hệ đổi theo. KHÔNG sửa header/footer trong từng trang.
2. Thêm trang mới → thêm 1 dòng vào file này (mục C) + vào `sol-nav.json` nếu muốn lên menu.
3. Đổi URL → sửa 1 chỗ ở `sol-nav.json`, đồng thời thêm redirect cũ→mới (khỏi hỏng SEO).
4. `sitemap.xml` (Rank Math) lo cho Google — tách bạch, không đụng tới menu.

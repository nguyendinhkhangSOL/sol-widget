## 🎨 CONTENT DESIGN GUIDELINES

### Voice + Tone

- **Không sáo mòn**: bỏ "trong thời đại 4.0", "chuyển đổi số"
- **Câu chuyện thật**: mỗi bài mở đầu bằng anecdote
- **Persona xuyên suốt**: Anh Tuấn 52 tuổi cựu CFO F&B (như Prompt Library)
- **Ngôi "tôi"**: giọng cá nhân, không "chúng tôi"
- **Số liệu cụ thể**: không "nhiều", "đáng kể"

### Format chuẩn mỗi bài

1. Hero image (16:9)
2. Meta title + description (Yoast/RankMath)
3. TOC ở đầu (auto-generated)
4. H2 mỗi 300-500 từ
5. 1-2 bullet lists per H2
6. 1 blockquote highlighted per bài
7. 1 case study box màu amber
8. 1 CTA box cuối bài
9. Related posts (3 bài) cuối
10. Author box (Khang Sol)

### Featured image style

Đồng bộ V4.1:
- Navy #0F172A background
- Amber accent #F59E0B
- Font Lora (title) + Inter (subtitle)
- 3 variants: Number-focused / Conversation / Chart

## 🎁 BONUS: Featured snippet targeting

Google top 3 = tốt. Nhưng Featured Snippet = position 0 = **golden**.

Structure content để chiếm featured snippet:

### Cho "định nghĩa" query
```
H2: [Keyword] là gì?

[Keyword] là ... (1-2 câu ngắn gọn, ~40-60 từ).
```

### Cho "list" query
```
H2: Top X [keyword]

1. Item 1
2. Item 2
...
```

### Cho "how-to" query
```
H2: Cách [keyword]

Bước 1: ...
Bước 2: ...
```

Mỗi bài cần identify featured snippet opportunity + optimize.

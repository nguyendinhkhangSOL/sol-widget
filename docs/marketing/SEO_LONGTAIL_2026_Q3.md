### On-page SEO checklist
| Element | Yêu cầu |
|---------|---------|
| H1 | 1 lần duy nhất, contain focus keyword |
| H2 | 4-6 H2, ≥2 H2 contain related keyword |
| First paragraph | Focus keyword xuất hiện trong 100 ký tự đầu |
| Image alt text | Tả ảnh + 1 keyword variant |
| Internal links | ≥3 link sang bài Sol khác |
| External links | 1-2 link nguồn nghiên cứu (Cochrane, WHO, CDC) — increase authority |
| FAQ Schema | 6-8 Q&A — eligible Rich Snippet |
| Word count | ≥1500 từ cho informational, ≥2500 từ cho PILLAR |
| Featured image | 1200×630 OG image với focus keyword |

## VIII. Anti-Patterns — đừng làm

### ❌ Keyword stuffing
Không repeat focus keyword 10+ lần. Google penalize. Density 0.5-1% là OK.

### ❌ Bài viết quá ngắn cho long-tail competitive
Thực phẩm giảm thèm (350 vol) — phải ≥1500 từ. <800 từ → không rank được.

### ❌ Copy nội dung từ bài này sang bài khác
Google detect duplicate → cả 2 bài drop ranking. Mỗi bài UNIQUE content.

### ❌ Quá phụ thuộc 1 cluster keyword
Tối đa 3-4 bài per cluster trong 30 ngày. Quá nhiều → cannibalization (bài tự cạnh tranh nhau).

### ❌ Submit Search Console quá nhanh
URL Inspection > Request Indexing — chỉ 10-15 URL/ngày. Quá nhiều → Google rate-limit.
